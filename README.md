# GH-Leather — локальный сайт ателье

Откройте index.html двойным кликом: сайт работает без сборки и интернета. Либо запустите START-SITE.cmd: он открывает http://127.0.0.1:4173 и запускает локальный сервер Python. Если порт уже занят, остановите предыдущий сервер либо выберите другой порт.

Ручной запуск из этой папки:
```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Исходники: index.html, styles.css, app.js. Локальные GSAP 3.15.0 и ScrollTrigger взяты из Website-Tools/vendor/gsap; README и уведомления сохранены в assets/lib. Сборка и npm не нужны.

Функции: выбор материала, раскрытие услуг и ответов, галерея с клавиатурой, меню на мобильном. Контакты ведут в Telegram, VK, карты, почту и телефон. Форм и сервера обработки данных нет; аналитика не подключена.
