# GH-Leather — локальный сайт ателье

Для полноценного предпросмотра с 3D запустите START-SITE.cmd (ES-модулям Three.js нужен HTTP-сервер): он открывает http://127.0.0.1:4173 и запускает локальный сервер Python. Если порт уже занят, остановите предыдущий сервер либо выберите другой порт.

Ручной запуск из этой папки:
```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Исходники: index.html, styles.css, experience.css, app.js, loader.js, studio.js. Локальные GSAP 3.15.0 и ScrollTrigger взяты из Website-Tools/vendor/gsap; README и уведомления сохранены в assets/lib. Сборка и npm не нужны.

Функции: выбор материала, раскрытие услуг и ответов, галерея с клавиатурой, меню на мобильном. Контакты ведут в Telegram, VK, карты, почту и телефон. Форм и сервера обработки данных нет; аналитика не подключена.

## Вступление и 3D
Короткая анимация кожаной куртки: бегунок молнии идёт вниз, борта расходятся, открывается сайт. Можно пропустить кнопкой или Escape, повторить из раздела 3D. Показывается один раз за сессию, отключается при prefers-reduced-motion. Если JavaScript недоступен, оверлей не создаётся.
Две оригинальные процедурные модели на Three.js: кожаная куртка и сумка. Вращение мышью/пальцем, кнопки и стрелки на клавиатуре; масштаб ползунком или +/-; Home и кнопка возвращают ракурс. Три оттенка кожи. Все ресурсы локальные. Рендер по запросу, без постоянного цикла. Модуль загружается возле секции, скрытая вкладка не рендерит. При отсутствии WebGL остаётся SVG-иллюстрация с пояснением. Модели — дизайнерские эскизы, не выполненные заказы.
Лицензия Three.js: assets/lib/THREE-LICENSE.txt (MIT), исходная версия из локального Website-Tools/vendor/three. Нумерация и полоса направлений удалены.
