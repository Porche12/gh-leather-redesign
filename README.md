# GH-Leather — локальный сайт ателье

Для полноценного предпросмотра с 3D запустите START-SITE.cmd (ES-модулям Three.js нужен HTTP-сервер): он открывает http://127.0.0.1:4173 и запускает локальный сервер Python. Если порт уже занят, остановите предыдущий сервер либо выберите другой порт.

Ручной запуск из этой папки:
```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Исходники: index.html, styles.css, experience.css, app.js, loader.js, studio.js. Локальные GSAP 3.15.0 и ScrollTrigger взяты из Website-Tools/vendor/gsap; README и уведомления сохранены в assets/lib. Сборка и npm не нужны.

Функции: выбор материала, раскрытие услуг и ответов, галерея с клавиатурой, меню на мобильном. Контакты ведут в Telegram, VK, карты, почту и телефон. Форм и сервера обработки данных нет; аналитика не подключена.

## Вступление и 3D
Короткая анимация ремонта ткани: игла проходит вдоль разрыва, бордовая нить стягивает края, после чего открывается сайт. Продолжительность около 1.9 секунды. Можно пропустить кнопкой или Escape и повторить из раздела 3D. Показывается один раз за сессию, отключается при prefers-reduced-motion. Без JavaScript оверлей не создаётся.

Осталась одна оригинальная процедурная модель на Three.js — кожаная сумка. Куртка, её геометрия, переключатель и иллюстрация удалены. Сумка поддерживает вращение мышью, пальцем, кнопками и стрелками; масштаб ползунком или +/-; Home и кнопка сбрасывают ракурс. Три оттенка кожи, локальные ресурсы, загрузка при приближении секции, рендеринг по запросу. Без WebGL остаётся иллюстрация сумки. Модель обозначена как дизайнерский эскиз, а не выполненный заказ.
