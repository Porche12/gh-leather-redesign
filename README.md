# GH-Leather — локальный сайт ателье

Для предпросмотра запустите START-SITE.cmd: он открывает http://127.0.0.1:4173 и запускает локальный сервер Python. Если порт уже занят, остановите предыдущий сервер либо выберите другой порт.

Ручной запуск из этой папки:
```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Исходники: index.html, styles.css, experience.css, app.js и loader.js. Локальные GSAP 3.15.0 и ScrollTrigger взяты из Website-Tools/vendor/gsap; README и уведомления сохранены в assets/lib. Сборка и npm не нужны.

Функции: переключаемый фотобаннер в первом экране, быстрые переходы к услугам, выбор материала, плавное раскрытие услуг, анимированные фотобаннеры, мобильное меню. Контакты ведут в Telegram, VK, карты, почту и телефон. Форм и аналитики нет.

## Источники
Данные GH-Leather проверены 02.11.2026 по https://gh-leather.ru/ и страницам /Контакты-Как-добраться, /Индивидуальный-пошив, /Реставрация-ремонт, /Пошив-одежды-из-ткани, /Сумки. В исходной ссылке пользователя отсутствовал дефис; правильный домен найден и проверен.

Три баннера одежды и мастерской взяты с Unsplash и оформлены как вдохновение, не как реальные работы ателье. Авторы и условия лицензии находятся в assets/sources.json.

Первый экран меняет фото и текст при выборе материала. Фотографии Unsplash используются как вдохновение, не как работы ателье.

## Вступление и образы
Короткая анимация ремонта ткани: игла проходит вдоль разрыва, бордовая нить стягивает края, после чего открывается сайт. Можно пропустить кнопкой или Escape. Показывается один раз за сессию и отключается при prefers-reduced-motion.

Вступление показывает, как игла зашивает ткань. Фото кожи, меха и текстиля выбираются переключателями, которые синхронизированы с материалами в разделе услуг.
