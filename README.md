# GH-Leather — локальный сайт ателье

Для полноценного предпросмотра с 3D запустите START-SITE.cmd (ES-модулям Three.js нужен HTTP-сервер): он открывает http://127.0.0.1:4173 и запускает локальный сервер Python. Если порт уже занят, остановите предыдущий сервер либо выберите другой порт.

Ручной запуск из этой папки:
```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Исходники: index.html, styles.css, experience.css, app.js, loader.js, studio.js. Локальные GSAP 3.15.0 и ScrollTrigger взяты из Website-Tools/vendor/gsap; README и уведомления сохранены в assets/lib. Сборка и npm не нужны.

Функции: интерактивная 3D-сумка в первом экране, быстрые переходы к услугам, выбор материала, плавное раскрытие услуг, галерея, мобильное меню. Контакты ведут в Telegram, VK, карты, почту и телефон. Форм и аналитики нет.

Фотографии взяты из публичной галереи GH-Leather. Оригинальные водяные знаки сохранены, источники — в assets/sources.json. Подтвердите права на фотографии и актуальность данных у владельца.

Первый экран — авторская процедурная 3D-модель сумки на Three.js, не фотография реального изделия. Ранее использовавшаяся AI-иллюстрация хранится в assets, но не отображается.

## Вступление и 3D
Короткая анимация ремонта ткани: игла проходит вдоль разрыва, бордовая нить стягивает края, после чего открывается сайт. Можно пропустить кнопкой или Escape. Показывается один раз за сессию и отключается при prefers-reduced-motion.

Осталась одна оригинальная процедурная модель на Three.js — кожаная сумка в первом экране. Куртка и её переключатель удалены. Модель вращается мышью, пальцем, кнопками и стрелками; три оттенка кожи и масштаб регулируются контролами. Ресурсы загружаются локально, WebGL имеет SVG-иллюстрацию как fallback. Это дизайнерский эскиз, не фото заказа.

Лицензия Three.js: assets/lib/THREE-LICENSE.txt (MIT), исходная версия из Website-Tools/vendor/three. Нумерация и полоса направлений удалены.
