# Инструкции агенту: сайты для бизнеса

## Начало работы
1. Прочитай README.md, docs/reference-analysis.md, docs/tool-map.md.
2. Работай в отдельном projects/<slug>, не меняй vendor. Если работаешь в созданном проекте, путь к набору записан в TOOLKIT.txt.
3. Прочитай бриф и выбранный рецепт. Недостающие факты помечай как требующие подтверждения. Можно продолжать композицию и разработку без них.
4. До реализации зафиксируй DESIGN.md: аудитория, основное действие, визуальная идея, последовательность разделов, палитра, типографика, одна ключевая интеракция, поведение на мобильном и при reduced motion.

## Дизайн
Создавай собственную композицию под бизнес. Три референса — разные направления, а не одна тема для всех. Выразительность строится на масштабе типографики, ритме, фотографиях, пространстве и полезной интеракции. Подбирай шрифты с кириллицей и проверяй их лицензию. Не используй одинаковые карточки для каждого блока. Выбирай один главный визуальный жест, поддерживай его деталями. Не копируй названия, контакты, отзывы, фото, логотипы и исходный код референсов.

## Технологии
Простой лендинг: HTML/CSS/JS, при необходимости Vite. React и сервер добавляй только под реальные требования. Читай документацию нужной библиотеки в vendor, сверяй версию. Используй минимум зависимостей. Не запускай сборки всех vendor-репозиториев. Для установки пакетов фиксируй версию и lockfile в проекте. Скачанный исходный репозиторий не означает установленный npm-пакет.
- GSAP + ScrollTrigger: сложные связанные анимации.
- Lenis: только если плавный скролл помогает, не ломай якоря и нативное управление.
- Three.js: оправданная интерактивная 3D-сцена с статичным fallback.
- SVG + обычный JS: схемы, интерактивный выбор услуги.
- PhotoSwipe: просмотр фотографий с клавиатурой и жестами.
- Embla: карусель с кнопками; автопрокрутка должна останавливаться.
- CSS + IntersectionObserver: простые появления без дополнительной библиотеки.

## Реализация и приёмка
Семантическая структура, видимый focus, подписи полей, доступное меню. Контент виден при выключенном JS. Анимации не блокируют действия. Учитывай prefers-reduced-motion и слабые устройства. Не подменяй курсор и не захватывай скролл без задачи. Эффекты приостанавливаются вне экрана и в скрытой вкладке. Фото с размерами, responsive images; hero без lazy loading, остальные по необходимости.
Все CTA должны выполнять обещанное действие. Формы имеют настоящий endpoint либо явное сообщение о деморежиме, без ложного «заявка отправлена». Секреты остаются на сервере. Цены, отзывы, сертификаты и цифры опыта берутся из подтверждённого брифа.
Проверь docs/quality-checklist.md. В завершение сообщи, что создано, как запустить, что проверено и что требует данных владельца. Не публикуй сайт без соответствующего запроса.
